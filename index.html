Student API reference

Only the current signal sample is visible

The simulator calls init() once per fresh run and filter() once per sampled input. Globals state, params, and memory are available in all helper functions. Do not declare these names at the top level.

Standard functions

init()
Optional; initialize memory before the first sample.
filter()
Required; returns one finite scalar output y.

state · current input only

state.x
The current input sample x[k]. There is no state.xPrev, index, timestamp, or future sample.

params · read-only test configuration

params.dt
Sampling interval Tₛ, seconds (1 / params.fs).
params.fs
Sampling rate (samples/second).
params.duration
Signal duration (10 s).
params.frequency
Current test sine frequency (Hz), including during a sweep.
params.amplitude
Input sine amplitude.
params.noiseStd
Noise standard deviation (white Gaussian noise).
params.offset
Input DC offset.
params.seed
Random seed for reproducible inputs.

memory · your persistent variables

memory starts empty and is reset before each independent run/sweep frequency. Your code owns its properties. Store previous input/output samples and filter state here.

function init() {
  memory.prevY = 0;
  memory.history = [];
}
// Inside filter():
memory.history.push(state.x);
const n = memory.history.length;
const previous = n >= 2 ? memory.history[n-2] : 0;

Read state and params; write memory; return one number. The reference sine and noise sequence are used for evaluation but are not given through state. For fair graded tests, don't reconstruct the reference from exposed test settings.
